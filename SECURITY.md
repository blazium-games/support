# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Do not open a public issue.

1. Go to [Report a vulnerability](https://github.com/blazium-games/support/security/advisories/new) (the **Security** tab of this repository, then **Report a vulnerability**).
2. Describe the problem, where it happens, and how to reproduce it.
3. Submit it. Only you and the Blazium Games team can see the report.

If you can't use GitHub, email [support@blazium.games](mailto:support@blazium.games) with "Security" in the subject.

We'll acknowledge the report, keep you updated in the advisory while we work on a fix, and credit you when we publish it, unless you'd rather stay anonymous.

## Scope

- [blazium.games](https://blazium.games), including developer and player accounts, the store, wallets, and payments
- The MCP servers at mcp.blazium.games
- The chauffeur CLI (`npm install -g @blazium-games/cli`) and its GitHub Action
- The [desktop launcher](https://github.com/blazium-games/games_launcher)
- The [skills package](https://github.com/blazium-games/games_skill) (`npm install @blazium-games/skills`)
- The crash reporting SDK
- The [documentation site](https://docs.blazium.games) and Cursor plugin

## Please don't

- Access, change, or delete other people's data. Use your own accounts for testing.
- Run denial-of-service tests, spam, or social engineering against users or staff.
- Post keys, login codes, or personal data in any report. Describe where you found them instead.
